Optimasi Metaheuristik: OOA & ChOA

Mempelajari Osprey Optimization Algorithm (OOA) dan Chimp Optimization Algorithm (ChOA) melalui formulasi matematis yang ketat, visualisasi topologi ruang pencarian, serta simulasi interaktif berbasis peramban web tanpa dependensi server.

01 / RUANG architecture

Search Space ($\Omega$)

Domain kontinu $D$-dimensi yang dibatasi oleh vektor batas bawah $\mathbf{lb}$ dan batas atas $\mathbf{ub}$.

02 / BIAYA functions

Fungsi Objektif

Pemetaan $f(\mathbf{x}): \Omega \to \mathbb{R}$ yang mencari minimum global $\min f(\mathbf{x})$ tanpa memerlukan turunan gradien.

03 / AGEN groups

Populasi Kolektif

Kumpulan $N$ vektor kandidat solusi $\mathbf{X}_i$ yang bergerak secara stokastik sepanjang $T$ iterasi.

04 / JELAJAH travel_explore

Exploration

Pencarian global berdispersi luas untuk mencegah perangkap optimum lokal (local optima trapping).

05 / FOKUS radar

Exploitation

Kontraksi dan penajaman solusi di sekitar kandidat terbaik menuju konvergensi presisi tinggi.

Avian Piscivore Metaheuristic

OOA: Osprey Optimization

Dehghani et al., 2023

Meniru perilaku pemangsaan ikan laut oleh burung elang tiram (Pandion haliaetus). Menggunakan strategi dua tahap: pendeteksian mangsa di dalam air (eksplorasi global) dan relokasi ke sarang tepi pantai (eksploitasi lokal intensif).

Fase Perilaku: 2-Tahap (Buru Ikan & Sarang Pantai)
Hiperparameter: Bebas Parameter (Stokastik $I \in \{1, 2\}$)

ChOA: Chimp Optimization

Khishe & Mosavi, 2020

Memodelkan kecerdasan kawanan simpanse dengan pembagian peran sosial: Penyerang ($\alpha$), Penghadang ($\beta$), Pengejar ($\gamma$), dan Penggiring ($\delta$). Menggabungkan fusi posisi rata-rata 4 pemimpin dengan modulasi chaotic map.

Kasta Sosial: Attacker, Barrier, Chaser, Driver
Modulasi Dinamis: Peluruhan $f$ & Chaotic Map

Alur Kerja Pipa Algoritma Optimasi (Optimization Workflow)

Iterative Architecture
01

Inisialisasi

Distribusi acak $N$ agen dalam batas pencarian $\mathbf{lb} \le \mathbf{X}_i \le \mathbf{ub}$.

02

Evaluasi

Menghitung nilai fungsi biaya $f(\mathbf{X}_i)$ dan mencatat solusi terbaik $X^*$.

03

Update Posisi

Menerapkan formulasi perpindahan (OOA perburuan atau ChOA 4-peran).

04

Clamping

Memproyeksikan agen yang melanggar batas kembali ke domain valid $\Omega$.

05

Seleksi Elitis

Penggantian serakah hanya jika posisi baru lebih baik ($f(\mathbf{X}^{baru}) < f(\mathbf{X}^{lama})$).

06

Konvergensi

Verifikasi syarat henti iterasi ($t \ge T$) dan mengembalikan $X^*$ optimal.

DOKUMENTASI TEORETIS 01

Osprey Optimization Algorithm (OOA)

Analisis komprehensif algoritma metaheuristik berbasis populasi yang meniru dua strategi berburu burung elang tiram laut (Dehghani, Trojovský, & Trojovská, 2023).

KOMPLEKSITAS WAKTU: $\mathcal{O}(T \times N \times D)$
flight_takeoff

Simulator 2D: Perilaku Penyelaman Osprey Menangkap Ikan

CANVAS 2D SIMULATOR

Amati dinamika dua lapisan: Osprey berpatroli di udara, mengidentifikasi kawanan ikan di bawah permukaan air laut, lalu menukik tajam (diving vector) sebelum membawa mangsa kembali ke pantai.

Osprey ($X_i$) Ikan Laut ($FP_i$) Klik canvas laut untuk menambah ikan
Ikan Aktif: 5 | Elang Osprey: 8
FASE 1: EKSPLORASI GLOBAL Hunting the Fish

Setiap osprey mendeteksi ikan yang direpresentasikan oleh agen berkinerja lebih unggul:

// Persamaan Perburuan Tahap 1
$$x_{i,j}^{P1} = x_{i,j} + r_1 \cdot \left(SF_{i,j} - I \cdot x_{i,j}\right)$$
Dimana $SF_i$ adalah ikan terpilih acak dari $\{X_k \mid f(X_k) < f(X_i)\} \cup \{X^*\}$, $r_1 \in [0, 1]$, dan $I \in \{1, 2\}$ adalah impuls acak untuk lompatan ruang.
FASE 2: EKSPLOITASI LOKAL Carrying Fish to Perch

Setelah menangkap ikan, osprey terbang ke sarang pantai, melakukan pencarian intensif:

// Persamaan Eksploitasi Tahap 2
$$x_{i,j}^{P2} = x_{i,j} + \frac{lb_j + r_2 \cdot (ub_j - lb_j)}{t}$$
Faktor $1/t$ menyusutkan radius pencarian seiring pertambahan iterasi, memusatkan konvergensi presisi di sekitar koordinat prima.

Flowchart Interaktif Siklus Hidup OOA

Klik tahapan di bawah untuk meninjau aturan matematisnya:

1. Pembentukan Matriks Posisi Ikan ($FP_i$) Identifikasi semua solusi $k$ dengan $f(X_k) < f(X_i)$.
2. Penyelaman Stokastik Berburu Ikan Hitung $X_i^{P1}$ dengan impuls lompat $I \in \{1, 2\}$.
3. Seleksi Elitis Serakah Tahap 1 Terima $X_i = X_i^{P1}$ jika dan hanya jika $f(X_i^{P1}) < f(X_i)$.
4. Relokasi Sarang Pantai Teredam $1/t$ Hitung $X_i^{P2}$ dengan kontraksi perimeter iteratif.
5. Seleksi Elitis Tahap 2 & Update $X^*$ Finalisasi posisi agen menuju generasi berikutnya.
Tahap 1 Terpilih: Himpunan ikan membentuk lingkungan adaptif. Jika tidak ada agen yang lebih baik, solusi terbaik global $X^*$ otomatis dijadikan target $SF_i$.
terminal Algoritma 1: Pseudocode Osprey Optimization (OOA) 
Input: Ukuran Populasi N, Iterasi Maksimum T, Batas Pencarian [lb, ub]
Output: Solusi Terbaik Global X* dan Nilai Biaya f(X*)

1:  Inisialisasi posisi awal X_i ~ U(lb, ub) untuk setiap i = 1, ..., N
2:  Evaluasi vektor fitness F_i = f(X_i); tentukan solusi terbaik X*
3:  for t = 1 to T do
4:      for i = 1 to N do
5:          // FASE 1: Identifikasi Posisi Ikan & Penyelaman (Eksplorasi)
6:          FP_i = { X_k | f(X_k) < f(X_i) } ∪ { X* }
7:          Pilih target acak SF_i ∈ FP_i
8:          I = round(1 + rand())  // Faktor impuls stokastik ∈ {1, 2}
9:          X_i,j^(P1) = X_i,j + rand() * (SF_i,j - I * X_i,j)
10:         TerapkanClampingBatas(X_i^(P1), lb, ub)
11:         if f(X_i^(P1)) < f(X_i) then X_i ← X_i^(P1)
12:
13:         // FASE 2: Membawa Ikan ke Sarang Pantai (Eksploitasi)
14:         X_i,j^(P2) = X_i,j + (lb_j + rand() * (ub_j - lb_j)) / t
15:         TerapkanClampingBatas(X_i^(P2), lb, ub)
16:         if f(X_i^(P2)) < f(X_i) then X_i ← X_i^(P2)
17:     end for
18:     Perbarui solusi terbaik global X* ← argmin f(X)
19: end for
20: return X*, f(X*)

Chimp Optimization Algorithm (ChOA)

Formulasi matematis dinamika sosial dan koordinasi berburu multi-agen terinspirasi oleh perilaku kawanan simpanse (Khishe & Mosavi, 2020).

PARADIGMA: FISSION-FUSION PACK HIERARCHY
α Peringkat 1

The Attacker (Penyerang)

Pemimpin elit dengan biaya objektif terendah. Mengarahkan koordinat serangan utama langsung ke posisi mangsa estimasi.

β Peringkat 2

The Barrier (Penghadang)

Kandidat terbaik kedua. Memposisikan diri memotong jalur pelarian mangsa di kanopi hutan, menutup celah diversifikasi ruang.

γ Peringkat 3

The Chaser (Pengejar)

Kandidat terbaik ketiga. Melakukan pengejaran berkecepatan tinggi di belakang mangsa untuk menggiringnya masuk ke perangkap.

δ Peringkat 4

The Driver (Penggiring)

Kandidat terbaik keempat. Berpatroli di koridor bawah, mengarahkan mangsa menuju zona sergap penyerang dan penghadang.

psychology

Model Konvergensi Vektor 4-Peran Simpanse

SOCIAL DYNAMICS

Demonstrasi interaktif bagaimana simpanse biasa menghitung perpindahan posisi relatif terhadap sentroid poligon yang dibentuk oleh $\alpha$, $\beta$, $\gamma$, dan $\delta$.

● α (Attacker) ● β (Barrier) ● γ (Chaser) ● δ (Driver) ● Sentroid
Kohesi Formasi: 4 Pemimpin Aktif
PENGURUNGAN MANGSA (ENCIRCLEMENT)

Jarak metrik dan perpindahan dihitung untuk tiap peran $j \in \{\alpha, \beta, \gamma, \delta\}$:

$$d_j = |c \cdot X_j - m \cdot X_i|, \quad X_j' = X_j - a \cdot d_j$$
Dimana $a = 2f \cdot r_1 - f$ meluruh dengan $f = 2.5 - (2.0t / T)$, $c = 2r_2$, dan $m$ adalah koefisien peta chaos.
FUSI SENTROID 4-VEKTOR

Kombinasi rata-rata dari keempat vektor kepemimpinan:

$$X_i(t+1) = \frac{X_1 + X_2 + X_3 + X_4}{4}$$
Jika probabilitas uji strategi acak memenuhi kondisi $\mu \ge 0.5$, agen mengeksekusi chaotic drive untuk mencegah jebakan lokal.

Flowchart Interaktif Prosedur ChOA

Klik tahapan berikut untuk meninjau detail implementasi:

1. Evaluasi & Penentuan Peran Sosial Identifikasi $\alpha$ (terbaik), $\beta$, $\gamma$, dan $\delta$.
2. Perhitungan Jarak Pengurungan Mangsa Hitung $d_\alpha, d_\beta, d_\gamma, d_\delta$ dengan peluruhan $f$.
3. Sintesis Fusi Sentroid Kuadran Rata-rata 4 vektor: $(X_1+X_2+X_3+X_4)/4$.
4. Percabangan Chaotic Hunting Drive Perturbasi chaos non-linear jika kondisi acak terpenuhi.
5. Penegakan Batas & Pembaruan Kasta Clamping dan pembaruan ranking untuk iterasi baru.
Tahap 1 Terpilih: Populasi diurutkan secara menaik berdasarkan nilai evaluasi fungsi objektif untuk menetapkan empat agen pemimpin sosial.
terminal Algoritma 2: Pseudocode Chimp Optimization (ChOA) 
Input: Ukuran Kawanan Simpanse N, Iterasi Maksimum T, Batas [lb, ub]
Output: Posisi Attacker X_alpha dan Nilai Biaya f(X_alpha)

1:  Inisialisasi populasi simpanse X_i ~ U(lb, ub) untuk i = 1, ..., N
2:  Evaluasi f(X_i); tetapkan 4 peran elit: X_alpha, X_beta, X_gamma, X_delta
3:  for t = 1 to T do
4:      f_decay = 2.5 - (2.0 * t / T)  // Faktor peluruhan dinamis
5:      for i = 1 to N do
6:          if rand() < 0.5 then
7:              // Mekanisme Pengurungan & Serangan Kooperatif
8:              d_alpha = |c1 * X_alpha - m1 * X_i|,  X1 = X_alpha - a1 * d_alpha
9:              d_beta  = |c2 * X_beta  - m2 * X_i|,  X2 = X_beta  - a2 * d_beta
10:             d_gamma = |c3 * X_gamma - m3 * X_i|,  X3 = X_gamma - a3 * d_gamma
11:             d_delta = |c4 * X_delta - m4 * X_i|,  X4 = X_delta - a4 * d_delta
12:             X_i(t+1) = (X1 + X2 + X3 + X4) / 4
13:         else
14:             // Gerakan Perturbasi Chaotic Map
15:             X_i(t+1) = lb + ChaoticValue() * (ub - lb)
16:         end if
17:         TerapkanClampingBatas(X_i(t+1), lb, ub)
18:         Evaluasi f(X_i(t+1))
19:     end for
20:     Perbarui peringkat elit: X_alpha, X_beta, X_gamma, X_delta
21: end for
22: return X_alpha, f(X_alpha)
